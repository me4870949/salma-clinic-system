# نظام إدارة عيادات مركز سلمي لطب الأسنان والجلدية - عرعر
## Salma Dental & Dermatology Clinic Management System

نظام ويب متكامل وسحابي لإدارة العمليات الطبية والإدارية والمالية لـ **"مركز سلمي لطب الأسنان والجلدية في عرعر"**، مصمم بواجهة عصرية فائقة البساطة (Minimalist UI) باللغة العربية (RTL) مع مسارات روابط إنجليزية (English URL Routes) ونظام مصادقة وأدوار متقدم.

---

## 1. مسارات الروابط وهيكلة النظام (English URL Routes)

| المسار (Route) | الوصف | الصلاحية / الدور (Role) |
|---|---|---|
| `/login` | صفحة تسجيل الدخول العصرية مع محول الحسابات التجريبية (Demo Switcher) | للجميع (Public) |
| `/dashboard/doctor` | لوحة تحكم الطبيب (طابور كشوفات اليوم، الفحص السريري، الروشتات) | الطبيب (Doctor) |
| `/dashboard/reception` | لوحة تحكم الاستقبال (تسجيل وصول المرضى، الحجوزات السريعة، تنظيم الانتظار) | موظف الاستقبال (Receptionist) |
| `/dashboard/finance` | لوحة الإدارة المالية (الإيرادات، المصروفات، ضريبة 15% ZATCA، تقارير الدفع) | المدير المالي (Financial Manager) |
| `/appointments` | جدول المواعيد وحجز المواعيد حسب التخصص (طب الأسنان / الجلدية والتجميل) | الطبيب، الاستقبال، الإدارة |
| `/patients` | سجل المرضى والملف الطبي الإلكتروني (EMR) ومخطط الأسنان والجلدية | الطبيب، الاستقبال |
| `/prescriptions` | إدارة الروشتات الإلكترونية والوصفات الطبية المعتمدة مع رمز QR والطباعة | الطبيب، الاستقبال |
| `/invoices` | الفواتير الضريبية المبسطة المتوافقة مع هيئة الزكاة والضريبة والجمارك (ZATCA) | المدير المالي، الاستقبال |
| `/whatsapp-notifications` | منصة إرسال إشعارات وتنبيهات الواتساب التلقائية والمخصصة للمرضى | الاستقبال، الإدارة |

## 3. المميزات الرئيسية

1. **مخطط الأسنان التفاعلي (Dental Chart)**:
   - فحص وترقيم 32 سن دائم وفق نظام FDI الدولي.
   - تشخيص وتوثيق: التسوس، علاج العصب، الحشوات التجميلية، التيجان، والزراعة مع تلوين فوري.
2. **خريطة جلسات الجلدية والليزر (Dermatology Map)**:
   - توثيق معايير أجهزة الليزر (Candela GentleMax Pro) من حيث طاقة الفلوينس، حجم العدسة، والنبضة.
   - توثيق حقن البوتوكس، الفيلر، وإبر النضارة بروفايلو والتقشير.
3. **الروشتة الطبية الإلكترونية (E-Prescriptions)**:
   - تحرير وحفظ وطباعة الوصفة الطبية بتهيئة رسمية معتمدة مع رمز تحقق QR ومشاركتها عبر الواتساب.
4. **الفواتير والامتثال الضريبي (ZATCA 15% VAT)**:
   - إنشاء فواتير ضريبية مبسطة بحساب تلقائي لضريبة 15% وطرق دفع متعددة (مدى، Apple Pay، تابي، كاش).
5. **محرك إشعارات الواتساب (WhatsApp Hub)**:
   - 5 قوالب مسبقة التجهيز بتعبئة تلقائية لبيانات المريض والموعد والإرسال المباشر بنقرة واحدة عبر `wa.me`.

## 4. التشغيل الفوري

### أ. التشغيل المباشر في المتصفح (بدون أي تثبيت):
يمكنك ببساطة فتح الملف `index.html` في أي متصفح (Edge / Chrome / Safari) بالنقر المزدوج عليه ليعمل النظام كاملاً بتفاعلية تامة!

### ب. التشغيل كمشروع Vite / React:
```bash
cd salma-clinic-system
npm install
npm run dev
```

### ج. النشر على Vercel أو Netlify:
المشروع مجهز بالكامل للرفع على Vercel أو Netlify مباشرة عبر ربط المستودع أو تنفيذ `vercel deploy`.
